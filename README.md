# Capstone AI Teaching Assistant

AI-powered teaching assistant that converts textbook PDFs into instructor-ready lesson plans.

## Current Features

- PDF upload with Streamlit
- Text extraction
- TOC extraction
- Chapter detection
- Section parsing
- Semantic structure reconstruction

## Planned Features

- Semantic chunking
- RAG retrieval
- Lesson generation
- Hallucination evaluation
- Rubric scoring
- Feedback regeneration loop

## Tech Stack

- Python
- Streamlit
- OpenAI API
- FAISS
- RAG architecture
